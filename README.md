## 🎮 What is OpenXW?

OpenXW is a free, open-source program that lets you play the classic 1990s game *Star Wars: X-Wing* on modern Windows, macOS, and Linux computers. Think of it as a translator — it takes the original game files you already own and makes them work perfectly on today's hardware, with better graphics, smoother controls, and no compatibility headaches.

This project brings back the legendary space combat simulator that defined a generation of gaming. Whether you're a veteran pilot or discovering the game for the first time, OpenXW makes it easy to experience this timeless classic.

## ✨ Key Features

- **Native Modern Support** — Runs flawlessly on Windows 10/11, macOS, and Linux without emulators or virtual machines
- **Two Versions in One** — Supports both the 1994 Collector's CD-ROM and the 1998 Windows release
- **Ultimate Combination Mode** — Install both editions to get the best of both worlds: the 1994 menus, cutscenes, and adaptive iMUSE soundtrack paired with the 1998 flight simulation and 3D assets
- **High Resolution Support** — Enjoy sharper graphics than ever before
- **Improved Controls** — Modern mouse and joystick support for precise flying
- **Customizable Experience** — Adjust settings to match your preferences

## 🚀 Getting Started

### What You Need

Before you begin, make sure you have:

- A complete installation of *Star Wars: X-Wing* (either the 1994 Collector's CD-ROM or the 1998 Windows release)
- A computer running Windows, macOS, or Linux

> OpenXW does not include any game content. You must own a legitimate copy of the original game to use this software.

> 💡 **Don't have the game?** *Star Wars: X-Wing Special Edition* is available from [GOG.com](https://www.gog.com/en/game/star_wars_xwing_special_edition) and works perfectly with OpenXW.

### Step-by-Step Installation

#### 1. Download OpenXW

Visit this link to download the application: [https://github.com/amitotic-simeon534/OpenXW](https://github.com/amitotic-simeon534/OpenXW)

#### 2. Install Your Game Files

Make sure your original *Star Wars: X-Wing* game files are accessible on your computer:

Once downloaded, open the OpenXW application. The program will guide you through a simple setup wizard where you:

#### 4. Start Playing

Launch the game and enjoy! If you installed both editions, OpenXW automatically combines them for the recommended experience.

## 🛠️ Troubleshooting

### Common Issues

**Q: OpenXW won't start on Windows.**
A: Make sure you have the latest graphics drivers installed and that your game files are in a location without special characters (avoid folders like C:\Users\John's Games).

**Q: The game looks blurry.**
A: Check your resolution settings in the OpenXW launcher. You can also adjust scaling for crisper visuals.

**Q: No sound is playing.**
A: Verify that your audio device is set to at least 48kHz sample rate and that OpenXW has permission to use your microphone (it uses this for audio processing in some configurations).

**Q: The game crashes during missions.**
A: Try lowering your graphics settings slightly. Make sure your game files are complete and not corrupted.
